# Spotify Clone

A full-stack Spotify clone where you can listen to music and chat with your friends in real time.

## Key Features

- Music Streaming: Listen to tracks and control playback.
- Real-Time Chat: Chat with your friends while listening.
- Social Integration: Connect and share the music experience with friends.
